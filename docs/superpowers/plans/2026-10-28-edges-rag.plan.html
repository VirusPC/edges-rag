服务启动时全量索引 INDEX_ROOT，向量写进本地 Chroma。

加载器只读白名单扩展名，并跳过排除目录。

启动先清空集合，再全量重建，最后启动 watcher。

文件变更时，索引按路径增量增、删、改。

watcher 把 watchdog 事件转成 upsert 或 delete。

upsert 先按路径删旧向量，再插新文档。

嵌入和回答都走 4070ts 上的 Ollama（Tailscale 地址）。

地址和模型名只来自环境变量；仓库里只放占位符。

.env.example 里聊天模型写什么占位？

共用：一个 Settings，所有模块从它读配置。

不做：MySQL、OpenAI 兼容接口、前端界面、个人 brain。

  • 不用 MySQL 或其他关系库。向量只在本地 Chroma。
  • v1 不提供 OpenAI 兼容接口。只有 POST /ask。
  • 不做官网前端。本服务只是后端问答。
  • 不索引个人 brain 或私有工作区。
  • 不管理 4070ts 上的 Ollama，也不自动拉模型。
  • 不做多租户、OAuth、配额。Docker 部署留到以后。
